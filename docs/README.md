## Règles de tenue à jour

1. **Toute décision** (produit, technique, sécurité) est notée dans le document concerné et dans son « Journal des révisions ».
2. **Toute fonctionnalité livrée** met à jour le `README.md` racine (section fonctionnalités et tableau réel / fictif / à confirmer) **dans la même PR**.
3. **Toute information externe** (loi, tarifs, limites d'un service) indique sa source, sa date et son niveau de fiabilité (vérifié / source secondaire / à confirmer).
4. **Aucune donnée inventée n'est présentée comme réelle** : tout ce qui est fictif reste marqué FICTIF.
5. Avant de fusionner une PR : relire ces documents et vérifier que rien n'est périmé.
